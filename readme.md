# Práctica: Tarjetas de Perfil

Hola, este es el repositorio de la práctica. El objetivo principal era crear las tarjetas de perfil que vimos en clase, aplicando los conceptos de CSS que nos pidieron.

## ¿Qué se usó?
- **HTML y CSS** estructurado.
- **FontAwesome** (vía CDN) para los iconos de las redes sociales y los botones de las tarjetas.
- **Clip-path** en CSS para hacer los cortes diagonales en la cabecera morada y en el pie de página azul.
- **Metodología BEM** para nombrar las clases (por eso se ven como `card__header`, `card__body`, etc.).
- **Posicionamiento absoluto** para lograr que las fotos queden justo en el medio de la tarjeta, montadas entre el fondo morado y el blanco, sin que se corten.
